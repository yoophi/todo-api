# Todo API

아주 평범한 Todo API 를 제공하는 REST API 샘플입니다.

## Requirements

- Python 3.9+
- PostgreSQL

## Dependencies

This project uses the latest versions of:
- Flask 3.1.2
- SQLAlchemy 2.0.44
- Flask-SQLAlchemy 3.1.1
- Flask-Migrate 4.1.0
- And other up-to-date dependencies

## Environments

- `DB_HOST`
- `DB_PORT`
- `DB_USER`
- `DB_PASSWORD`
- `DB_DATABASE`
